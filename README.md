# NativeBiz English Coach

Master business English through real-world news and AI-powered coaching.

## ✨ Features

- 🎯 **Personalized Learning**: Select your interest categories for customized content
- 📰 **Real-World Topics**: Practice with current business news and trends
- 🎤 **Shadowing Practice**: Improve pronunciation with AI feedback
- 💬 **Discussion Sessions**: Enhance speaking skills with guided conversations
- 📱 **Mobile Optimized**: Fully responsive design for all devices
- 💾 **Preference Storage**: Your interests are saved locally
- 🌐 **PWA Ready**: Install as a native-like app on mobile devices

## 🚀 Run Locally

**Prerequisites:**  Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set the `GEMINI_API_KEY` in `.env.local`:
   ```bash
   GEMINI_API_KEY=your_api_key_here
   ```

3. Run the app:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000)
